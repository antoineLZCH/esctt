# ES Colombienne Tennis de table

Vocabulaire du club utilisé pour orienter les futurs adhérents.

## Language

**Profil de joueur** : Public auquel un créneau est adapté : Jeune (mineur), Adulte loisir ou Adulte compétition. Un même créneau peut accueillir plusieurs profils.

**Créneau** : Plage horaire hebdomadaire de pratique dans un lieu donné, destinée à un ou plusieurs profils de joueurs.

**Catégorie tarifaire** : Catégorie déterminant le tarif selon les conditions d’adhésion. Elle est distincte du profil de joueur : la catégorie tarifaire « Jeunes / étudiants » ne désigne pas nécessairement des mineurs.

**Tournoi interne** : Tournoi organisé dans le cadre de la vie du club, présenté séparément des compétitions FFTT.
